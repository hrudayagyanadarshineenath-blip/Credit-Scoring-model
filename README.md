# Credit Scoring Model using Machine Learning

## 📌 Project Overview

This project focuses on building a **Credit Scoring Model using Machine Learning** to predict whether a loan applicant is likely to default on a loan.

The project was developed as part of a Machine Learning internship/project and uses the **Credit Risk Dataset**. Different machine learning classification algorithms were trained and evaluated to compare their performance in predicting loan default risk.

The target variable used in the project is `loan_status`:

- `0` → Non-default
- `1` → Default

---

## 🎯 Objectives

The main objectives of this project are:

- Load and understand the credit risk dataset.
- Perform data cleaning and preprocessing.
- Handle missing values and duplicate records.
- Explore the dataset using data analysis and visualization.
- Prepare the data for machine learning.
- Train multiple classification models.
- Evaluate the models using different performance metrics.
- Compare the performance of the trained models.
- Select an appropriate model based on the evaluation results.
- Use the selected model to make a prediction for a new customer.

---

## 📊 Dataset

The project uses the **Credit Risk Dataset**.

### Dataset Features

The dataset contains information related to:

- Person age
- Person income
- Home ownership
- Employment length
- Loan intent
- Loan grade
- Loan amount
- Loan interest rate
- Loan percentage of income
- Previous default history
- Credit history length
